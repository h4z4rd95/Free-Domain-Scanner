## 🎯 معرفی پروژه
DomainHub یک سیستم پیشرفته و ماژولار برای جستجوی دامنه‌های اینترنتی، بررسی وضعیت ثبت، و مدیریت سفارشات است. این سیستم با طراحی کاملاً بومی و غیرماشینی، امکان اتصال به ارائه‌دهندگان مختلف هاست، سرور مجازی و دامنه را فراهم می‌کند.

### اهداف اصلی
- جستجوی دامنه با پشتیبانی از تمام پسوندهای Namecheap
- نمایش تاریخچه جستجو بر اساس دستگاه کاربر
- سیستم پرداخت کارت به کارت با تأیید دستی ادمین
- داشبوردهای کاربری و مدیریتی پیشرفته
- تبدیل نرخ دلار به تومان با آپدیت روزانه
- پشتیبانی از دامنه‌های .ir و بین‌المللی
- سیستم پیشنهاد دامنه جایگزین
- ذخیره‌سازی هوشمند داده‌های جستجو برای خدمات آینده

## ✨ ویژگی‌های کلیدی

### 🔍 جستجوی پیشرفته دامنه
- پشتیبانی از بیش از 500 پسوند دامنه
- فیلتر دسته‌بندی شده (تجاری، شخصی، تخصصی)
- نمایش وضعیت دامنه (آزاد، ثبت‌شده، منقضی‌شده)
- Whois داخلی بدون خروج از سایت
- پیشنهاد دامنه‌های جایگزین هوشمند

### 💰 سیستم مالی
- تعریف قیمت‌ها به دلار و نمایش به تومان
- دریافت نرخ روز دلار از منابع ایرانی (با فال‌بک خودکار)
- پرداخت کارت به کارت با چندین شماره کارت
- آپلود رسید پرداخت و تأیید دستی
- مدیریت وضعیت سفارشات (معلق، موفق، خطا)

### 📊 داشبوردها
#### داشبورد کاربری
- مشاهده تاریخچه جستجوهای شخصی
- لیست سفارشات و وضعیت آن‌ها
- نمودار فعالیت‌ها
- یادآور تمدید دامنه
- پیشنهادات تخفیف دوره‌ای

#### داشبورد مدیریتی
- مدیریت کاربران و نقش‌ها
- تعریف و ویرایش تعرفه‌ها
- تنظیمات درگاه پرداخت و کارت‌ها
- مشاهده گزارش‌های فروش و درآمد
- مدیریت لاگ‌های سیستم
- تأیید/رد سفارشات پرداخت دستی

### 🔐 امنیت و لاگینگ
- لاگینگ دو سطحی (ادمین: جزئیات کامل، کاربر: Toast)
- ذخیره‌سازی کوکی‌محور برای کاربران مهمان
- پاک‌سازی خودکار داده‌های موقت
- اعتبارسنجی ورودی‌ها

## 🏗️ معماری سیستم

### تکنولوژی‌های استفاده‌شده
- **Backend**: PHP Native (معماری MVC سفارشی)
- **Database**: MySQL (سازگار با cPanel و DirectAdmin)
- **Frontend**: 
  - HTML5, CSS3 (طراحی اختصاصی غیرماشینی)
  - JavaScript Vanilla + Motion.dev برای انیمیشن‌ها
  - Scroll-driven Animations
  - کامپوننت‌های لوکال از Shadcn Blocks, Uiverse, Lordicon
- **External APIs**: 
  - Namecheap (بررسی دامنه و Whois)
  - منابع نرخ ارز ایرانی (با فال‌بک)
  - Hetzner & AWS (در فازهای بعدی)

### الگوی طراحی
- **MVC سفارشی**: کنترل کامل روی کد بدون وابستگی به فریم‌ورک‌های سنگین
- **ماژولار**: قابلیت افزودن سرویس‌های جدید بدون تغییر در هسته
- **Repository Pattern**: جداسازی لایه دسترسی به داده
- **Service Layer**: مدیریت منطق کسب‌وکار

## 🔌 APIهای متصل

### فعلی
- **Namecheap API**: بررسی موجود بودن دامنه، Whois، لیست پسوندها
- **منابع نرخ ارز**: 
  - Primary: Bonbast.com
  - Fallback: TGJU.org
  - کش روزانه با آپدیت ساعتی

### فازهای بعدی
- **Hetzner API**: سرورهای مجازی
- **Amazon AWS API**: خدمات ابری
- **پرووایدرهای ایرانی**: پارس‌آنلاین، آسیاتک، etc.

## 💳 سیستم پرداخت

### روش‌های پرداخت
1. **کارت به کارت دستی**
   - تعریف چندین شماره کارت در پنل مدیریت
   - نمایش رندوم یا اولویت‌بندی‌شده
   - آپلود رسید پرداخت
   - تأیید دستی توسط ادمین

2. **درگاه‌های ایرانی** (فاز بعدی)
   - آقای پرداخت
   - زرین‌پال
   - نکست‌پی

### گردش کار پرداخت دستی
```
کاربر → انتخاب دامنه → نمایش اطلاعات کارت → واریز → آپلود رسید 
→ ثبت سفارش با وضعیت "معلق" → تأیید ادمین → تغییر وضعیت به "موفق" 
→ ارسال通知 به کاربر
```
